# QuickStash

UGREEN NAS（UGOS Pro）上の画像・動画・PDF を快適に閲覧・整理するための個人用 Android ギャラリーアプリ。SMB 経由で NAS に直接接続し、純正アプリよりも軽快な閲覧体験とキュレーション機能を提供する。

> 個人利用・サイドロード（APK 直接インストール）専用。Google Play では配布しない。

## 主な機能

### 閲覧
- フォルダブラウズ（サムネイルカード表示・中身プレビュー付き）
- 画像ビューア（ズーム・スワイプ・回転・フォルダ間移動）
- 動画再生（シークバー・倍速・A-B ループ・ダブルタップスキップ・横スワイプシーク・明るさ調整）
- PDF 表示、GIF アニメーション
- スライドショー（順次／ランダム、円形カウントダウンタイマー、グループ連続再生）
- 自然順ソート（a-1 … a-11 を数値順に）

### 整理・キュレーション
- 並べ替え（名前／サイズ／タイプ／追加日時／類似画像／グループの複合、優先順位指定）
- 類似画像ソート（知覚ハッシュ dHash + HSV ヒストグラム）
- グループ化（長押し選択 → 選択順で採番、A-1 バッジ）
- Tier（手動 Tier + 閲覧統計からの自動 Tier、バッジ・フィルタ）
- タグ（自由命名・複数付与・フォルダ横断 = 実質アルバム）
- フィルタ（タイプ／Tier／タグ）
- ファイル名検索（訪問済みフォルダを索引化）

### ファイル操作
- 端末 → NAS アップロード（写真・動画／任意ファイル）
- 新規フォルダ作成・フォルダ削除
- 一括移動・一括リネーム（選択順連番）・削除

### その他
- 生体認証アプリロック
- NAS への自動バックアップ（24 時間ごと・世代ローテート 5 世代）と手動バックアップ／復元
- 外出先アクセス（セカンダリホスト + 自動フォールバック、Tailscale 併用を想定）
- 画像キャッシュの自動整理（LRU・上限付き）

## 隠れ操作リファレンス

| 操作 | 挙動 |
|------|------|
| グリッドで 2 本指ピンチ | 列数を 2〜6 で変更 |
| メディアを長押し | 選択モード開始（選択中は全画面プレビュー） |
| 動画再生画面を横スワイプ | シーク（全幅 = 動画全長） |
| 動画を左右ダブルタップ | スキップ（秒数は設定） |
| ロック画面の南京錠をタップ | 生体認証を再要求 |

## 技術スタック

- Kotlin + Jetpack Compose（Material 3）
- SMB: SMBJ（接続プール 4 本、1MB 読み取りバッファ）
- 画像: Coil 3 + カスタム Fetcher（サムネイル／原画／動画サムネ／PDF サムネ）
- 動画: Media3 ExoPlayer + カスタム SmbDataSource
- 永続化: Room（SQLite）、DataStore（設定）
- DI: 手動（AppContainer）
- minSdk 26 / targetSdk 36

## ビルド

```bash
# デバッグビルド + 実機インストール
./gradlew :app:installDebug

# リリースビルド（R8 有効、約 8.8MB）
./gradlew :app:assembleRelease

# ユニットテスト
./gradlew :app:testDebugUnitTest
```

リリースビルドは動作確認用にデバッグ鍵で署名している（サイドロード前提）。

## セットアップ

1. NAS 側で SMB サービスを有効化する
2. アプリの設定画面でホスト（IP アドレス）・共有名・ユーザー名・パスワード・ルートパスを入力
3. 「接続テスト」で疎通を確認して保存

### 外出先アクセス（任意）

NAS とスマートフォンに Tailscale を導入し、設定画面の「セカンダリホスト」に NAS の Tailscale IP を入力する。自宅では LAN、外出先では Tailscale 経由に自動でフォールバックする。

## データの扱い

- 認証情報は Android Keystore で暗号化して端末内に保存する（AES/GCM）
- タグ・Tier・グループなどのキュレーション情報は端末内の Room DB に保存し、NAS 上の JSON にバックアップする
- NAS 上のファイル自体は移動・リネーム・削除・アップロードを除き変更しない（フォルダ分けは DB 上の対応のみ）
